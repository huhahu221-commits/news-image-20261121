One image that sums up Saturday 21 November 2026's world news, drawn as a
newspaper front page: the ICJ's genocide ruling against Myanmar, Russia's
400-drone strike on Ukraine and the missiles that fell in Poland, the AI-led
selloff that put the S&P 500 into correction, bitcoin under $60,000, the
pancreatic-cancer pill trial, COP31's overtime, the Peru earthquake and more.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to the output directory; the image is drawn
offline by `tools/generate.py` (Python 3 + Pillow) and committed beside it.
